# Scholar Wise Africa feed

Public data feed for scholarwiseafrica.com, refreshed hourly by Scholarship Scout.

- `opportunities.json`: open scholarships, fellowships, internships, funded conferences, calls for papers and grants
- `admissions.json`: self-funded programmes open for applications
- `widget.js`: optional embed that lists the opportunities with search and filters

Served at https://mbuwul.github.io/scholarship-feed/
